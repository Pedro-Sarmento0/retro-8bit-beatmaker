# Retro 8-Bit Beatmaker

A simple drum machine and chiptune synthesizer that runs entirely in the browser. You can use your keyboard to play retro 8-bit sounds.

## How it works

This project was built using standard HTML, CSS, and JavaScript. 

It doesn't use any external audio files (.mp3 or .wav). All the sounds (kicks, lasers, coins, etc.) are generated in real-time using the native Web Audio API.

## Usage

You don't need to install anything. To play with it:
1. Clone or download this repository.
2. Open the `index.html` file in any browser.
3. Press the A, S, D, F, G, H, J, K keys on your keyboard to play the sounds.
